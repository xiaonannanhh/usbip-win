USBRelay 局域网打印共享说明
============================

一、软件定位

USBRelay 是重新架构的局域网打印转发软件，主要用于 USB 打印机。
服务端继续使用本机 Windows 打印队列，客户端通过自定义协议把打印数据
发送给服务端，再由服务端调用本机打印后台处理。服务端本地打印功能不受
影响，多个客户端可以同时使用同一台服务端上的打印队列。

本软件不使用 Windows 打印机共享、SMB、UNC 路径、NetBIOS 打印共享、
USB/IP、VHCI、stub 驱动、USB 虚拟化或任何内核驱动。客户端安装的是
用户态打印端口监视器 DLL；客户端只创建 USBRELAY 本地端口，不自动创建
打印机队列，也不提供或安装打印机驱动。驱动选择与安装由用户在 Windows
“添加打印机”向导中按厂商要求自行完成，不会修改服务端的物理 USB 打印机
或原有打印端口。

二、系统要求

- Windows 7 SP1 或更高版本。
- 支持 32 位和 64 位 Windows。
- 服务端和客户端可以混合架构。32 位客户端可以连接 64 位服务端。
- 安装、创建本地端口、添加打印机和卸载需要管理员权限。
- 服务端和客户端的 Print Spooler 服务需要启用。

安装包尚未进行 Authenticode 数字签名，因此 Windows 可能显示“未知发布者”、
UAC 提示或 SmartScreen 警告。请先核对发布目录中的 SHA256SUMS.txt，再选择
“更多信息”并确认运行；正式分发前建议使用受信任代码签名证书签名。

三、网络端口

- UDP 3241：服务端广播发现信息，客户端接收广播。
- TCP 3242：获取打印机列表、主动探测服务端和传输 RAW 打印任务。

服务端会枚举所有处于启用状态且已连接的非回环 IPv4 网卡，分别向各网卡所在
子网的定向广播地址发送发现信息，并保留 255.255.255.255 全局广播作为兼容
回退。同时存在 Wi-Fi、有线网卡和 VirtualBox、VMware、Hyper-V 等虚拟网卡时，
不会只从其中一张网卡发出广播。

客户端除监听 UDP 广播外，还会在后台执行 TCP 主动探测：优先尝试上次保存的
服务端名称或地址，并检查本机 ARP/邻居表及所在 IPv4 网段。只有 TCP 3242
返回 USBRelay 打印协议响应时才会加入发现列表。这样即使服务端是未升级的旧
版本，或者其广播只从虚拟网卡发出，新客户端仍可自动找到服务端。主动探测不会
创建打印机端口，也不会创建队列或安装驱动。

服务端安装器只添加 TCP 3242 和 UDP 3241 两条 USBRelay 防火墙规则；
客户端安装器只添加 UDP 3241。不会添加 135、139、445，也不会启用
Windows 打印共享。

四、服务端使用

1. 在安装服务端的计算机上运行服务端安装包。
2. 安装完成后，服务端 UI 会打开，并在当前用户会话中启动隐藏的打印共享
   进程；本版本不创建 Windows 服务，退出 UI 时会同时停止该隐藏进程。
3. UI 中可以刷新本机打印机列表、打开 Windows 打印机管理、启动或停止打印
   共享。
4. 列表显示的是本机已有的 Windows 打印队列。USBRelay 不会把本机打印机
   从系统中解绑，也不会改变本机原有端口。
5. 服务端会定期在 UDP 3241 广播计算机名、IPv4 来源地址对应的发现信息
   和打印机数量。

服务端安装目录：

    %ProgramFiles%\USBRelay\Server

五、客户端使用

1. 在客户端计算机上运行客户端安装包。
2. 客户端打开后会自动监听 UDP 3241，并在后台执行 TCP 主动探测；通常数秒到
   约 30 秒内会显示局域网内发现的服务端，无需预先输入地址。
3. 发现列表同时显示服务端计算机名和 IPv4 地址。选择服务端后，客户端
   会自动请求并展示服务端发布的打印机列表。
   客户端还会把上次使用的服务端和最近一次成功获取的打印机元数据保存在
   当前用户注册表中。下次启动时先立即显示上次状态，随后自动刷新；服务端
   暂时无法连接时保留上次列表，不会把已显示内容清空。
4. 也可以在“地址/计算机名”输入框中填写服务端计算机名、IPv4 地址或
   可解析的 DNS 名称，然后点击“刷新打印机”。
5. 选择打印机，点击“创建本地端口”。客户端只创建端口，不会弹出或自动
   建立打印机队列，也不会检查、安装或下载驱动。
6. 点击“打开添加打印机”，在 Windows 向导中选择“添加本地打印机”，
   再选择“使用现有端口”中的 `USBRELAY:` 端口。随后按厂商驱动包的要求
   选择或安装匹配的打印机驱动。USBRelay 不附带、不下载、不代替用户安装
   厂商驱动；x64 Windows 应使用 x64 驱动，x86 Windows 应使用 x86 驱动。
7. 添加完成后，Windows 应用就可以像使用普通本地打印机一样打印；需要时
   再点击“设为默认”。如果尚未安装合适驱动，Windows 添加打印机流程会
   按系统正常方式要求提供驱动。

客户端使用 USBRELAY: 开头的自定义本地端口，例如：

    USBRELAY:SERVER-NAME:1234ABCD

只有 USBRELAY: 开头的队列和端口会被客户端清理或卸载。用户已有的普通
打印机队列不会被删除。

客户端安装目录：

    %ProgramFiles%\USBRelay\Client

六、托盘、快捷方式和开机启动

服务端和客户端都有独立的 Win32 UI，使用用户指定的“语音朗读器”图标。
安装包会创建桌面和开始菜单快捷方式。勾选 UI 中的开机启动选项后，
登录系统会启动对应 UI 并驻留右下角托盘。

双击托盘图标可唤起主界面；右键托盘图标选择“退出”可退出 UI，同时停止
由该 UI 守护的后台打印共享进程。需要随登录自动驻留托盘时，请勾选界面中的
“界面开机启动并驻留托盘”。

七、卸载

使用对应安装包的 /uninstall 参数，或在解压目录中以管理员身份运行：

    uninstall-server.cmd
    uninstall-client.cmd

客户端卸载顺序为：停止客户端 UI、清理 USBRELAY: 队列、停止打印后台、
移除 USBRelay 端口监视器注册和 DLL、启动打印后台、删除防火墙规则、
快捷方式、任务和客户端目录。服务端卸载会停止 UI 与后台打印共享进程，
并移除 USBRelay 防火墙规则、快捷方式、任务和服务端目录，不删除 Windows
打印队列。

安装服务端时，如果检测到旧 usbipd 服务，只有当其二进制路径完全等于：

    C:\Program Files\USBIP-Win7\usbipd.exe

或该路径带有旧项目的 --service 参数时，才会删除该旧服务以及以下两个旧
目录：

    C:\Program Files\USBIP-Win7
    C:\Program Files\USBIP-Win7-Client

以下目录始终保留，不会被本项目安装器删除：

    C:\Program Files\USBip
    C:\Program Files\usbipd-win
    C:\Program Files\USBRelayHost

八、常见问题

1. 看不到服务端：确认服务端 UI 和后台打印共享正在运行；确认服务端防火墙
   允许 TCP 3242 入站（客户端会主动探测），并允许 UDP 3241 广播；等待约
   30 秒后刷新。旧版服务端即使不升级，也可以被新版客户端主动发现；也可以
   直接输入服务端计算机名或 IPv4 地址。
2. 能看到服务端但读不到打印机：确认 TCP 3242 可达，并确认服务端本机
   Windows 打印队列正常。
3. 创建本地端口失败：确认客户端已以管理员身份运行，并确认 Print Spooler
   正常运行。端口创建与本地驱动是否已安装无关。
4. 添加打印机时没有可选驱动：这是 Windows 驱动库或厂商驱动包的问题，
   请通过 Windows 添加打印机向导安装与服务端匹配的 x86/x64 厂商驱动。
5. 添加打印机时找不到端口：确认客户端状态显示“端口已创建”，并在 Windows
   添加打印机向导中选择“使用现有端口”，不要选择“创建新端口”。
6. 打印失败：检查服务端 UI 与后台打印共享进程、TCP 3242、防火墙，以及
   服务端本地打印机是否可以直接打印。
