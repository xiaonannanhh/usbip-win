打印机内网共享服务端
====================

用途
----
本程序把服务端计算机上已经安装好的 Windows 本地打印机发布为
RAW TCP 端口。客户端使用 Windows 自带的“Standard TCP/IP Port”
连接服务端计算机名和对应端口，然后安装匹配的打印机驱动。

本程序不使用 Windows 打印机共享、SMB、UNC、NetBIOS 打印机共享、
USB/IP、VHCI、端口监视器或内核驱动。服务端打印队列和 USB 打印机
保持原状，本机仍可正常打印。

系统要求
--------
- Windows 7 SP1 或更高版本。
- 32 位系统使用 x86 安装包，64 位系统使用 x64 或 Universal 安装包。
- 服务端和客户端应处于可互相访问的同一局域网。
- 服务端必须已经安装并可正常使用目标打印机。
- 安装、卸载和修改开机启动需要使用管理员权限。

架构兼容性
----------
- x86 客户端可以连接 x64 服务端，x64 客户端也可以连接 x86 服务端。
- 32 位 Windows 使用 x86 安装包。
- 64 位 Windows 使用 x64 安装包，或使用 Universal 安装包。
- Universal 安装包会自动检测系统架构并运行对应的安装程序。

快速使用
--------
1. 在连接打印机的计算机上运行服务端安装包。
2. 安装完成后，服务端 UI 会自动启动并列出每台打印机的
   “Standard TCP/IP 端点”，例如 DESKTOP-GZEJK10:9102。
3. 也可以使用打印机内网共享配置工具端；工具自动发现
   服务端后，会在服务端下拉列表中直接显示该服务端发布的全部端口，
   例如“DESKTOP-GZEJK10 (192.168.1.20) - 4 台 - 端口 9100,9101,9102,9103”。
4. 使用 Windows“添加打印机”创建 Standard TCP/IP Port。
5. 主机名填写服务端 UI 显示的计算机名，RAW 端口填写对应数字。
6. 安装匹配的打印机驱动并打印测试页。

安装后的默认目录
----------------
%ProgramFiles%\USBRelay\StandardServer

安装程序会自动：
- 创建桌面快捷方式和开始菜单快捷方式。
- 创建登录启动任务，启动后在系统右下角显示托盘图标。
- 启动 RAW 服务并发布所有本机打印队列。
- 添加 TCP 9100-9199 和 UDP 3251 的入站防火墙规则。

任务日志池
----------
服务端记录每个打印任务的客户端 IP/计算机名、打印机、端口、接收字节数、
结束方式和处理结果。日志文件位于：

    %ProgramData%\USBRelay\StandardServer\server-task-log.txt

界面中的关键词框会对日志行做不区分大小写的全文筛选，可输入客户端计算机名、
客户端 IP、打印机名、端口号、任务结果或结束方式，再单击“筛选”；清空关键词
或单击“清除筛选”可恢复全部记录。单击“清理日志池”并确认后会清空已有任务日志，
后续任务仍会继续记录。清理与写入使用同一互斥锁，即使清理时有新任务完成也不会
互相覆盖；打印队列、端口、驱动和正在处理的打印任务均不受影响。日志文件达到
8 MB 时会自动清空后继续记录。

服务端界面
----------
界面列出打印机名称、驱动、原端口、RAW 端口、连接端点和服务状态。
“Standard TCP/IP 端点”列显示的格式为：

    服务端计算机名:9100
    服务端计算机名:9101
    ...
    服务端计算机名:9199

端口映射保存在：

    HKEY_LOCAL_MACHINE\SOFTWARE\USBRelay\StandardServer\Ports

端口不是按每次启动的顺序临时分配。服务端第一次识别一台打印机时，
会使用稳定的设备标识建立“设备-端口”锁定记录；同一台打印机在服务端
重启、Windows 重启以及 x86/x64 版本切换后仍使用原端口。只有端口确实
被其他程序占用，或管理员清除了对应的锁定记录时，才会重新分配。
若本机打印队列超过 100 台，超出部分不会发布。

客户端创建端口
--------------
客户端不需要安装本程序。请使用 Windows 自带的添加打印机流程：

1. 打开“控制面板”->“设备和打印机”。
2. 选择“添加打印机”。
3. 选择“添加本地打印机”。
4. 选择“创建新端口”。
5. 端口类型选择“Standard TCP/IP Port”。
6. 在“主机名或 IP 地址”中填写服务端 UI 显示的计算机名，例如
   DESKTOP-GZEJK10。通常不需要填写 IP 地址。
7. 端口名可自动生成；“设备类型”选择“TCP/IP Device”。
8. 协议选择 RAW，端口号填写该打印机在服务端 UI 中显示的
   9100-9199 端口。
9. 在 Windows 驱动安装页面选择或安装与服务端打印机匹配的驱动。
10. 完成向导后打印测试页。

不要选择“网络、无线或 Bluetooth 打印机”，也不要把服务端打印机
作为共享打印机添加。这里创建的是客户端本地的 Standard TCP/IP
端口，数据会发送到本服务端。

计算机名连接说明
----------------
客户端和服务端必须能解析计算机名。可在客户端命令提示符执行：

    ping 服务端计算机名

如果解析失败，请检查两台计算机是否在同一网络、网络配置文件中是否
允许网络发现，以及 DNS/NetBIOS 名称解析是否正常。计算机名连接比
固定 IP 更适合 DHCP 环境。

打印任务的结束与排队规则
------------------------
- 一个 TCP 连接视为一个打印任务。
- 服务端允许多个客户端同时建立 TCP 连接并发送任务；每个连接都有独立的接收线程
  和临时任务文件，一个客户端不会阻塞其他客户端的连接。
- 客户端发送 TCP FIN（正常关闭连接）时，服务端立即结束当前任务。
- 连接建立后首字节等待最长 500 毫秒；如果 500 毫秒内没有收到任何数据，服务端
  自动关闭这个空闲连接。
- 收到首个数据后，最后一次收到数据后连续 50 毫秒没有新数据时，服务端自动结束
  当前任务。
- 每个打印机拥有独立的串行打印队列。同一打印机的多个连接按到达顺序
  逐个处理，前一个任务结束前，后一个任务不会向该打印机交错写入。
- 不同打印机拥有不同的工作线程，可以并行处理。
- 任务结束后，服务端把已接收的 RAW 数据交给对应 Windows 打印队列；
  无论客户端随后断开还是关机，都不会解除服务端的 USB 打印机绑定。

协议与安全
----------
- UDP 3251：服务端发现广播和查询响应。
- TCP 9100-9199：RAW 打印数据。
- 服务端不解码打印内容，只转发原始字节。
- 本协议没有身份验证和加密，只应部署在可信局域网，不应把
  9100-9199 端口直接暴露到互联网。

常见问题
--------
1. 客户端找不到计算机名
   先执行 ping。若名称解析不可用，临时可用 IPv4 地址测试，但长期
   建议修复 DNS、NetBIOS 或本地 HOSTS 配置。

2. 客户端连接失败
   检查服务端 UI 是否显示“服务运行中”，确认 9100-9199 入站规则
   未被其他安全软件阻止，并确认客户端填写的端口正确。

3. 能连接但打印不出内容
   确认客户端使用 RAW 协议，确认端口号对应服务端 UI 中的打印机，
   确认服务端该打印队列可正常本地打印，并使用匹配的打印机驱动。

4. 本机 USB 打印机是否会断开
   不会。本程序只向现有 Windows 打印队列写入数据，不解绑 USB，
   不修改原端口，也不停止本机打印。

5. 是否需要安装本程序到客户端
   不需要。客户端仅使用 Windows 自带的 Standard TCP/IP Port。

卸载
----
运行安装目录中的 uninstall-standard-server.cmd，或安装包：

    USBRelay-Standard-Server-Setup-x86.exe /uninstall
    USBRelay-Standard-Server-Setup-x64.exe /uninstall

卸载会停止服务、删除启动任务、快捷方式、防火墙规则、端口映射和
程序目录，不会卸载或删除用户原有打印机和打印机驱动。
