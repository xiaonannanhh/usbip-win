# 打印机内网共享配置工具端使用说明书

## 1. 工具定位

本工具用于在客户端计算机上创建 Windows 自带的
`Standard TCP/IP Port`，连接打印机内网共享服务端发布的
打印机 RAW 端口。

本工具只管理端口，不安装打印机驱动，不创建打印队列，不使用 Windows
打印机共享、SMB、USB/IP 或 VHCI。

## 2. 支持环境

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 7 SP1 或更高版本 |
| 32 位系统 | 使用 x86 安装包 |
| 64 位系统 | 使用 x64 或 Universal 安装包 |
| 权限 | 安装、卸载、创建和删除端口需要管理员权限 |
| 依赖 | Print Spooler 服务可用 |
| 网络 | 与服务端同一局域网，UDP 3251 可通 |

Universal 安装包会检测当前系统架构，并自动运行对应的 x86 或 x64
安装程序。x86 客户端可以连接 x64 服务端，x64 客户端也可以连接
x86 服务端。

## 3. 安装

1. 双击对应的安装程序。
2. 安装程序会复制文件到 `%ProgramFiles%\USBRelay\PortTool`。
3. 程序会创建桌面快捷方式、开始菜单快捷方式和登录启动任务。
4. 程序会添加仅用于 UDP 3251 发现的入站防火墙规则。
5. 安装完成后，端口工具会自动启动，并在系统右下角保留托盘图标。

安装过程中会调用 Windows 端口监视器接口。该接口要求管理员权限，
因此安装程序需要以管理员身份运行。

## 4. 自动发现服务端

端口工具启动后会自动：

- 读取上一次保存的服务端和打印机缓存。
- 向局域网发送 UDP 3251 发现查询。
- 接收服务端广播和响应。

一般情况下不需要填写 IP 地址，也不需要配置服务端地址。

发现到服务端后，服务端下拉列表会直接显示该服务端发布的全部 RAW 端口，
例如：

```text
DESKTOP-GZEJK10  (192.168.1.20)  - 4 台 - 端口 9100,9101,9102,9103
```

同一个服务端允许多个客户端同时发送任务。每个客户端连接都是独立任务；同一
台打印机的任务按进入顺序进入独立 FIFO 队列，不会互相交错，不同打印机可以
并行打印。

服务端第一次识别打印机后会建立稳定的设备与端口锁定关系。服务端重启、
Windows 重启或 x86/x64 版本切换后仍沿用原端口，避免设备与端口号错乱。
客户端再次启动时会先从本地缓存恢复上次结果，不必等待广播重新出现。

如果列表中没有出现服务端：

1. 确认服务端 UI 正在运行。
2. 确认客户端和服务端在同一网段。
3. 检查 Windows 防火墙和交换机是否允许 UDP 3251。
4. 在右侧输入服务端计算机名，单击“名称连接”。

手动输入 IP 也可用于排查网络问题，但创建的端口默认使用服务端计算机名，
这样服务端 IP 变化后不需要重新创建端口。

## 5. 创建端口

1. 在“发现的服务端”列表中选择服务端。
2. 在打印机列表中选择目标打印机。
3. 确认“驱动”“连接主机”“RAW 端口”和“本地端口名称”。
4. 单击“添加所选端口”。

端口名称格式：

```text
驱动名首段_服务端计算机名_RAW端口
```

例如：

```text
HP_DESKTOP-GZEJK10_9102
```

驱动名首段取驱动名称第一个空格前的信息。相同驱动、计算机名和 RAW
端口会生成相同的本地端口名称。

创建成功后，在 Windows 中完成打印机队列配置：

1. 打开“控制面板” -> “设备和打印机”。
2. 单击“添加打印机”。
3. 选择“添加本地打印机”。
4. 选择“使用现有端口”。
5. 选择刚才创建的端口。
6. 安装与服务端打印机匹配的驱动。
7. 打印测试页。

本工具不会自动安装驱动。若 Windows 没有对应驱动，请先从打印机厂商
安装匹配的驱动包，再重新执行添加打印机向导。

### 检测连接

选择打印机后单击“检测连接”。工具会在后台解析服务端计算机名，并尝试
连接该打印机对应的 RAW TCP 端口，名称解析和 TCP 连接共用最多 5 秒的
总时限。连接成功后立即关闭 TCP 连接，不发送打印数据，也不会创建、删除
或修改端口。

检测成功表示计算机名已解析且对应 TCP 端口接受连接；这不能确认客户端
打印机队列、驱动、服务端打印后台处理程序或实体打印机状态，也不会提交
测试页。服务端可能把探测连接记录为 `bytes=0` 的忽略连接，不会放入打印队列。
若失败或超时，请检查服务端是否运行并发布该端口、名称解析、防火墙以及客户端
到服务端的网络连通性。

## 6. 缓存和离线状态

工具会把最近一次发现结果保存到：

```text
%LOCALAPPDATA%\USBRelay\PortTool\discovery-cache.ini
```

再次打开工具时会先显示缓存，不需要等待服务端再次广播。服务端离线后，
打印机状态会变为“缓存，服务端离线”。此时仍可按缓存信息创建端口，
但工具会先要求确认。

缓存只保存服务端、打印机名称、驱动、RAW 端口和端点，不保存打印内容，
也不保存打印驱动。

### 清理本地缓存

当服务端更换、设备信息发生变化，或客户端出现旧服务端/旧打印机信息冲突时，
单击界面中的“清理本地缓存”按钮并确认。工具会删除：

```text
%LOCALAPPDATA%\USBRelay\PortTool\discovery-cache.ini
```

随后清空当前窗口的服务端和打印机列表，并立即重新发送 UDP 3251 发现查询。
服务端重新响应后，最新设备信息会重新显示并生成新的缓存。

这个操作只清理客户端发现缓存，不会删除已经创建的 Standard TCP/IP Port，
不会删除本地打印机队列，也不会卸载或修改打印机驱动。没有缓存文件时，
清理操作仍然会清空当前内存中的发现结果并重新查询。

## 7. 托盘和开机启动

- 关闭主窗口只会隐藏到系统托盘。
- 双击托盘图标可以重新打开主窗口。
- 右键托盘图标可以打开主窗口或退出。
- 安装包默认启用登录启动任务。
- 可以通过界面中的“开机启动并驻留系统托盘”复选框关闭或重新开启。

开机启动任务名称：

```text
USBRelay-Standard-Port-Tool-Autostart
```

## 8. 命令行

添加端口：

```bat
usbrelay-port-tool-ui.exe /add-port 服务端计算机名 /port 9100
```

指定端口名称：

```bat
usbrelay-port-tool-ui.exe /add-port 服务端计算机名 /port 9100 ^
  /port-name USBRelay_Test_9100
```

删除端口：

```bat
usbrelay-port-tool-ui.exe /delete-port USBRelay_Test_9100
```

命令行模式仍然需要管理员权限。删除端口不会删除使用该端口的打印队列，
也不会卸载打印机驱动。

## 9. 卸载

运行安装目录中的：

```text
%ProgramFiles%\USBRelay\PortTool\uninstall-port-tool.cmd
```

也可以直接运行对应架构的安装包并带参数：

```bat
USBRelay-Standard-Port-Tool-Setup-x86.exe /uninstall
USBRelay-Standard-Port-Tool-Setup-x64.exe /uninstall
USBRelay-Standard-Port-Tool-Setup-Universal.exe /uninstall
```

卸载会删除程序目录、快捷方式、登录启动任务和 UDP 3251 防火墙规则。
用户已经创建的 Standard TCP/IP 端口、打印队列和打印机驱动会被保留，
避免误删现有打印配置。需要时请在 Windows 端口管理界面手动删除端口。

## 10. 故障排查

### 找不到服务端

- 检查服务端 UI 是否显示正在运行。
- 在客户端执行 `ping 服务端计算机名`。
- 确认 UDP 3251 未被防火墙、路由器或安全软件阻断。
- 尝试在“名称连接”输入框中直接输入服务端计算机名。

### 创建端口失败

- 确认当前程序以管理员身份运行。
- 确认 Print Spooler 服务正在运行。
- 确认端口名称没有重复，或先删除旧端口。
- 确认服务端对应 RAW 端口仍在 9100-9199 范围内。

### 端口创建后无法打印

- 确认打印机队列使用的是 `USBRelay_` 端口。
- 确认服务端对应打印机可以本地正常打印。
- 确认客户端安装了正确的打印机驱动。
- 确认服务端防火墙允许 TCP 9100-9199。
- 确认服务端与客户端之间没有阻止 RAW TCP 打印流量。

### 服务端 IP 改变后需要重做吗

如果端口使用服务端计算机名，通常不需要重做。必须确保客户端能够解析
服务端计算机名。如果端口手动填写的是固定 IP，请更新端口配置。
