打印机内网共享配置工具端
========================

用途
----
本工具是本机 Windows Standard TCP/IP Port 创建器。它会自动发现
局域网内的打印机内网共享服务端，列出服务端发布的打印机，
并在本机创建指向“服务端计算机名 + RAW 端口”的 Standard TCP/IP 端口。

本工具只创建端口，不安装打印机驱动，不创建打印队列，不使用 Windows
打印机共享、SMB、USB/IP、VHCI 或内核驱动。创建端口后，请使用 Windows
“添加打印机”向导选择已有端口并安装与服务端匹配的打印机驱动。

系统要求
--------
- Windows 7 SP1 或更高版本。
- 32 位系统使用 x86 安装包，64 位系统使用 x64 或 Universal 安装包。
- 创建端口需要管理员权限。
- 本机 Print Spooler 服务必须可用。
- 服务端和本工具所在计算机应在同一局域网。

自动发现
--------
工具启动后会监听并主动发送 UDP 3251 发现查询，不需要填写服务端地址。
服务端广播返回后，可在“发现的服务端”列表中选择服务端。若广播被网络
设备隔离，可在右侧输入服务端计算机名或 IP，单击“名称连接”。

发现到服务端后，服务端下拉列表会直接显示该服务端当前发布的所有 RAW
端口。例如：

    DESKTOP-GZEJK10  (192.168.1.20)  - 4 台 - 端口 9100,9101,9102,9103

多个客户端可以同时连接同一个服务端发送打印任务。服务端会为同一台打印机
按接收顺序排入独立 FIFO 队列；不同打印机之间可以并行处理，客户端不需要
等待前一个客户端完成打印。

服务端首次为打印机分配端口后，会把稳定设备标识和端口号锁定；服务端
重启或 Windows 重启不会打乱已发布端口。客户端再次启动时，也会先从
本地缓存恢复上次看到的端口列表。

连接方式
--------
创建的端口的“连接主机”默认为服务端计算机名，而不是固定 IP。这样在
DHCP 环境中服务端 IP 变化后，端口仍可通过名称解析连接。请确保 DNS、
NetBIOS 或 HOSTS 能让本机解析服务端计算机名。

添加端口
--------
1. 在列表中选择服务端。
2. 在打印机列表中选择目标打印机。
3. 单击“添加所选端口”。
4. 打开“设备和打印机”，选择“添加打印机”。
5. 选择“添加本地打印机”。
6. 选择“使用现有端口”，选中按驱动名、计算机名和端口号生成的端口。
7. 安装与服务端打印机匹配的驱动。

端口名称格式为：

    驱动名首段_服务端计算机名_RAW端口

例如：

    HP_DESKTOP-GZEJK10_9102

驱动名首段是驱动名称第一个空格前的内容。相同驱动、服务端计算机名和
RAW 端口会生成相同端口名，便于重复检查。

缓存与离线状态
--------------
工具会把最近一次发现到的服务端、打印机、驱动、RAW 端口和端点保存到：

    %LOCALAPPDATA%\USBRelay\PortTool\discovery-cache.ini

下次启动时先显示缓存。服务端离线后，打印机显示“缓存，服务端离线”，
仍可选择缓存信息创建端口；工具会要求确认。缓存只用于显示和创建端口，
不会代替真实连接测试。

清理本地缓存
------------
如果服务端更换过、端口列表显示旧设备，或需要重新发现局域网服务端，
单击界面中的“清理本地缓存”按钮，确认后工具会：

- 删除 `%LOCALAPPDATA%\USBRelay\PortTool\discovery-cache.ini`。
- 清空当前窗口中的服务端和打印机发现结果。
- 立即重新发送局域网发现查询，等待服务端返回最新列表。

清理缓存不会删除本机已经创建的 Standard TCP/IP Port，不会删除打印机队列，
也不会卸载打印机驱动。没有缓存文件时也可以执行，工具会直接清空当前发现数据
并重新查询。服务端重新被发现后，新的服务端和打印机信息会自动重新写入缓存。

检测连接
--------
选择打印机后单击“检测连接”。工具会在后台解析服务端计算机名，并尝试
连接该打印机对应的 RAW TCP 端口，名称解析和 TCP 连接共用最多 5 秒的
总时限。连接成功后立即关闭 TCP 连接，不发送打印数据，也不会创建、删除
或修改端口。

检测成功表示计算机名已解析且对应 TCP 端口接受连接；这不能确认客户端
打印机队列、驱动、服务端打印后台处理程序或实体打印机状态，也不会提交
测试页。服务端可能把探测连接记录为 bytes=0 的忽略连接，不会放入打印队列。
若失败或超时，请检查服务端是否运行并发布该端口、名称解析、防火墙以及客户端
到服务端的网络连通性。

托盘和开机启动
--------------
- 安装包默认创建开机启动任务，运行时驻留系统托盘。
- 单击窗口关闭按钮只隐藏窗口，不退出程序。
- 右键托盘图标可打开主界面或退出。
- “开机启动并驻留系统托盘”复选框可随时启用或关闭任务。

命令行
------
创建端口：

    usbrelay-port-tool-ui.exe /add-port 服务端计算机名 /port 9100

指定端口名：

    usbrelay-port-tool-ui.exe /add-port 服务端计算机名 /port 9100 /port-name USBRelay_Test_9100

删除端口：

    usbrelay-port-tool-ui.exe /delete-port 端口名

命令行模式仍然需要管理员权限。删除命令只删除本机端口，不删除打印队列，
也不会卸载打印机驱动。

常见问题
--------
1. 没有发现服务端
   检查两台计算机是否在同一网段、服务端 UI 是否正在运行、UDP 3251 是否
   被防火墙或交换机隔离，也可直接输入服务端计算机名测试名称连接。

2. 计算机名无法解析
   在命令提示符执行 ping 服务端计算机名。必要时修复 DNS、NetBIOS 或
   本地 HOSTS。若长期使用 IP，可在 Windows 创建端口向导中手动填写 IP，
   但服务端 IP 变化后需要更新端口。

3. 创建端口失败
   确认工具以管理员身份运行、Print Spooler 服务已启动，并确认端口名未被
   其他程序占用。错误代码可配合 Windows 的 net helpmsg 查询。

4. 端口创建后打印不出来
   确认 Windows 打印队列选择的是 USBRelay_ 端口，服务端对应打印机可本地
   打印，客户端使用匹配驱动，并确认服务端防火墙允许 TCP 9100-9199。

5. 卸载后端口是否还在
   会保留。卸载工具不会自动删除用户创建的 Standard TCP/IP 端口，也不会
   删除打印队列和驱动，避免误删现有打印配置。

安全说明
--------
发现使用 UDP 3251，打印数据使用 TCP 9100-9199。协议没有身份验证和加密，
只应部署在可信局域网，不应把服务端端口直接暴露到互联网。

安装目录
--------
%ProgramFiles%\USBRelay\PortTool
