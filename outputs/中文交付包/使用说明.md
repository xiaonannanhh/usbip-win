# 打印机内网共享使用说明

## 1. 软件组成

交付包包含服务端和配置工具端两个混合安装包。两者分别安装在连接打印机的电脑和需要使用该打印机的电脑上。混合安装包会检查 Windows 架构，并调用对应的 x86 或 x64 安装程序；32 位客户端和 64 位服务端可以互相连接。

软件最低支持 Windows 7 SP1。计算机应处于能够互相通信的局域网。服务端电脑需要已安装并能正常使用目标打印机。

本软件通过 Standard TCP/IP Port 的 RAW TCP 连接传送打印数据，不使用 Windows 打印机共享、SMB、USB/IP 或 VHCI。服务端继续使用本机已有的打印机和打印队列，打印机仍可在服务端本地使用。客户端需要有匹配的打印机驱动；配置工具只创建和维护端口，不安装驱动，也不创建打印机队列。

## 2. 安装

分别运行交付目录中的两个混合安装包。安装和卸载都需要管理员权限。安装程序根据系统架构自动选择程序版本，并完成快捷方式、登录启动任务和所需的防火墙规则。

安装目录如下：

- 服务端：`%ProgramFiles%\USBRelay\StandardServer`
- 配置工具端：`%ProgramFiles%\USBRelay\PortTool`

实际目录由安装程序运行架构和 Windows 环境决定，可能位于 `C:\Program Files` 或 `C:\Program Files (x86)`。安装完成后，可通过桌面快捷方式的“属性”查看程序实际位置。

## 3. 配置服务端

在接有 USB 打印机的电脑安装并打开“打印机内网共享服务端”。界面会列出本机 Windows 打印队列、驱动、原有端口、分配的 RAW 端口、计算机名端点和运行状态。程序启动时会自动启动 RAW 服务并发布可用的本机打印队列。

每台打印机首次发布时都会分配一个 9100 至 9199 范围内的 RAW 端口，并保存设备与端口的对应关系。重启服务端或 Windows 后会继续使用已保存的端口号，避免端口顺序变化。若端口因外部原因被占用，界面会显示相应状态。

服务端电脑仍可直接使用原有打印机队列打印。共享服务端把收到的 RAW 数据交给对应 Windows 打印队列处理，不会解绑 USB 打印机，也不要求停止本机打印。

## 4. 在客户端发现和选择打印机

在需要打印的电脑安装“打印机内网共享配置工具端”并启动。工具先读取上次发现缓存，然后刷新本机 DNS 缓存并检查缓存中的服务端名称；同时通过 UDP 3251 自动发现局域网内正在运行的服务端。正常情况下无需输入 IP 地址。

选择发现列表中的服务端后，工具会显示该服务端发布的打印机、驱动、连接主机、RAW 端口、本地端口名称和本机端口状态。若广播受网络隔离影响，可在名称连接框输入服务端计算机名连接。也可输入 IPv4 地址用于排查网络问题。

计算机名连接要求客户端能解析服务端名称。若名称连接失败，可在客户端执行 `ping 服务端计算机名` 检查解析和连通性。DHCP 环境中，服务端计算机名通常比固定 IP 更适合作为稳定标识。

## 5. 创建端口和打印机队列

在配置工具端选择服务端，再选择要使用的打印机并单击“添加所选端口”。端口名称按以下规则生成：

```text
驱动名称第一个空格前的内容_服务端计算机名_RAW端口号
```

例如：`Gprinter_DESKTOP-GZEJK10_9106`。工具创建的是本机 Windows 的 Standard TCP/IP Port，目标是服务端广播来源 IP 和对应 RAW 端口。重复添加同名端口时，工具会提示端口已存在。

端口创建后，还需在 Windows 中创建打印机队列并安装驱动：

1. 打开“控制面板”中的“设备和打印机”，选择“添加打印机”。
2. 选择“添加本地打印机”。
3. 选择“使用现有端口”，并选中刚创建的端口。
4. 选择或安装与服务端打印机相匹配的驱动。
5. 完成向导后打印测试页。

配置工具不会替代 Windows 打印机队列，也不会安装驱动。若电脑没有对应驱动，请先安装打印机厂商提供的驱动，再完成添加打印机向导。

也可以在 Windows 添加打印机向导中手动创建 Standard TCP/IP Port：选择“创建新端口”，端口类型选择“Standard TCP/IP Port”，主机填写服务端当前 IPv4 地址，协议选择 RAW，端口号填写服务端界面中该打印机对应的号码。使用配置工具可以自动发现端口，并在服务端 IP 变化后更新已有端口。

## 6. 服务端 IP 变化时的端口更新

配置工具启动时会尝试刷新本机 DNS 缓存。发现在线服务端时，工具以 UDP 广播数据包的实际来源 IPv4 地址作为优先地址，而不是盲目采用广播内容中可能过期的地址或 DNS 缓存地址。工具会先检测这个地址上的对应 RAW TCP 端口；只有连接验证通过后才执行更新。

更新时，工具在本机查找由 Standard TCP/IP Port 监视器管理、协议为 RAW、端口号相同，并且本地端口名称中服务端计算机名和 RAW 端口号匹配的端口。匹配的端口可以有多个，工具会逐一处理。只有目标 IP 确实发生变化时才写入新地址；端口名称、RAW 端口号和使用这些端口的打印机队列保持不变。

工具会在收到服务端广播时检查端口。若新广播地址上的 RAW TCP 端口暂不可连接，工具暂不修改配置，并会在后续广播重试。更新需要足够的 Windows 打印管理权限；安装包和程序要求管理员权限。如果更新失败，旧 IP 会保留，工具日志会显示结果。工具没有运行时不会自动更新端口，因而 IP 已变化而工具未运行或更新失败时，已有端口仍可能指向旧地址。请打开配置工具，确认日志报告更新成功后再测试打印。

DNS 检查结果也会记入界面日志。若 DNS 解析与广播来源地址不一致，工具仍以已验证的广播来源地址作为端口目标。DNS 刷新或检查失败时，自动发现和广播地址验证仍会继续，但计算机名连接能力可能受本机网络名称解析配置影响。

## 7. 连接检测、缓存和托盘

### 连接检测

选择打印机并单击“检测连接”，工具会尝试连接对应的服务端地址和 RAW TCP 端口。检测不发送打印数据，也不会创建或修改端口。检测成功只代表网络连接可建立，不代表驱动、打印队列、服务端 Windows 打印后台处理程序或实体打印机状态正常。

### 本地发现缓存

工具把最近发现的服务端、打印机和端口信息保存在：

```text
%LOCALAPPDATA%\USBRelay\PortTool\discovery-cache.ini
```

下次启动时会先显示缓存，因此不用等待服务端再次出现才看到上次的设备列表。服务端离线时，缓存信息会标记为离线；按离线缓存创建端口前，工具会要求确认。缓存不包含打印内容或打印驱动。

若服务端或设备信息已变化、列表出现旧数据或缓存冲突，可点击“清理本地缓存”。该操作清除发现缓存和当前列表，然后重新搜索服务端，不会删除 Standard TCP/IP Port、打印机队列或驱动。

### 开机启动和托盘

安装程序默认创建登录启动任务。程序启动后会在 Windows 通知区域（系统托盘）驻留。关闭窗口只会隐藏界面；双击托盘图标可重新打开窗口，右键图标可打开窗口或退出程序。界面中的“开机启动并驻留系统托盘”复选框可启用或关闭登录启动任务。任务以当前 Windows 用户登录时启动，并使用最高可用权限；若系统策略不允许，任务可能无法创建或无法取得足够权限。

服务端退出时会停止其后台 RAW 服务。配置工具退出后不会再接收广播，也不会继续检测或更新端口 IP；已有打印机端口和队列会保留。

## 8. 服务端任务队列和日志

每个 TCP 连接对应一个打印任务。服务端允许多个客户端同时发送；不同打印机可以并行处理，同一打印机的任务按接收顺序进入独立串行队列。

- 客户端正常发送 TCP FIN 时，服务端立即结束该任务。
- 连接建立后最多等待 500 毫秒接收首字节；没有数据时，服务端关闭空连接。
- 收到数据后，若连续 50 毫秒没有新数据，服务端自动结束任务。
- 任务结束后，服务端将已接收的 RAW 数据交给对应的 Windows 打印队列。

服务端日志记录客户端 IP、可解析的客户端计算机名、目标打印机、端口、字节数、任务结束原因和处理结果。日志位于 `%ProgramData%\USBRelay\StandardServer\server-task-log.txt`。界面支持按关键词筛选和清理日志池。日志达到 8 MB 时程序会清空旧日志后继续记录。探测连接可能产生零字节记录，但不会进入打印队列。

## 9. 网络端口和安全

服务端使用 UDP 3251 进行发现，使用 TCP 9100 至 9199 接收 RAW 打印数据。安装程序会为服务端添加对应的 Windows 防火墙入站规则；配置工具端添加 UDP 3251 发现规则。

打印协议没有身份验证或加密，应只用于可信局域网。不要将 UDP 3251 或 TCP 9100 至 9199 直接暴露到互联网。若计算机使用多个网络适配器或多个隔离网段，请确认客户端和服务端之间实际使用的网卡、路由和防火墙规则允许 UDP 广播及 RAW TCP 连接。

## 10. 常见故障

### 自动发现列表为空

确认服务端程序正在运行并显示服务运行中，客户端和服务端处于可互通的局域网，并允许 UDP 3251 广播。部分无线 AP、访客网络、VLAN 或安全软件会隔离广播。可尝试输入服务端计算机名使用名称连接。

### 连接检测显示错误 IP 或超时

打开配置工具查看日志中的广播来源地址、DNS 解析和 TCP 检测结果。当前工具以实际收到的广播来源 IP 为优先地址，并需验证对应打印机端口。检查服务端是否运行、端口号是否正确、TCP 9100 至 9199 是否被防火墙或安全软件阻止，以及两台电脑之间是否有路由。

### 创建或更新端口失败

确认程序以管理员身份运行，Windows Print Spooler 服务可用，并确认端口名称没有冲突。更新 IP 需要 Standard TCP/IP Port 监视器管理权限；权限不足时日志会显示错误，旧 IP 会保持不变。

### 端口已更新但打印无反应

确认 Windows 打印机队列选择了新建的 Standard TCP/IP Port，客户端已安装匹配驱动，服务端对应打印机可本地打印，且队列没有暂停或脱机。再检查 RAW 端口号、防火墙和服务端任务日志。连接检测不是打印测试页。

### 清理缓存后端口仍存在

这是预期行为。清理本地缓存只影响工具的发现数据，不会删除 Windows 打印端口、打印机队列或驱动。若需删除端口，请先处理正在使用它的打印机队列，再通过配置工具的删除端口功能操作。

## 11. 卸载

分别进入各自安装目录运行 `uninstall-standard-server.cmd` 或 `uninstall-port-tool.cmd`，也可重新运行对应安装包并按界面提示卸载。卸载需要管理员权限。

卸载服务端会停止后台服务、移除服务端启动任务、快捷方式、防火墙规则、端口映射和程序文件；不会卸载用户原有打印机或驱动。卸载配置工具会移除工具程序、启动任务、快捷方式和发现防火墙规则；已创建的 Standard TCP/IP Port、打印机队列和驱动会保留，避免影响现有打印配置。
